# Solar Panel Optimization Simulator

## Deskripsi Project

Solar Panel Optimization Simulator adalah aplikasi web simulasi optimasi penempatan panel surya pada atap rumah berbentuk grid 10x10.

Aplikasi ini menggunakan tiga algoritma optimasi:

- Hill Climbing
- Simulated Annealing
- Genetic Algorithm

Tujuan dari aplikasi ini adalah mencari posisi panel surya terbaik agar total energi yang dihasilkan menjadi maksimum.

---

## Fitur Aplikasi

- Visualisasi grid atap 10x10
- Penempatan panel surya otomatis
- Implementasi Hill Climbing
- Implementasi Simulated Annealing
- Implementasi Genetic Algorithm
- Grafik konvergensi setiap algoritma
- Grafik perbandingan energi
- Ranking algoritma terbaik
- Kesimpulan otomatis hasil simulasi
